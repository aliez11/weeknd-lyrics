# 🌙 AFTER HOURS — Lyric Flipbook

**A little lyric companion for the nights we sing together.**

> *Made for the concert. Built for the memories.*

一个为 The Weeknd 演唱会准备的交互式歌词翻页本。

起因很简单：演唱会快到了，想把那些听过无数遍、却总是唱不完整的歌词真正记下来。

比起在不同歌词网站之间切换，我更想要一本可以翻页、标记、遮挡和反复练习的电子歌词本。

于是有了这个小项目。

### 🎧 Live Demo

**[Open Lyric Flipbook →](https://aliez11.github.io/weeknd-lyrics/)**

### ✨ Features

| Feature | Description |
|---|---|
| 📖 Lyric Flipbook | 按歌曲翻页，专注阅读 |
| 🔠 Adjustable Font Size | 自由调整字号，适配手机阅读 |
| 🎤 Sing-Along Highlights | 标记重点歌词与合唱候选段落 |
| 🙈 Memory Practice | 隐藏歌词，测试自己的记忆 |
| ✅ Learning Progress | 标记已经背会的歌曲 |
| 🔀 Shuffle Mode | 随机抽歌练习 |
| 🌗 Dark / Light Mode | 深浅主题自由切换 |
| 📱 Mobile Friendly | 手机、平板和电脑均可使用 |

### 🪩 Why I Made This

**Because knowing every song doesn't mean knowing every word.**

熟悉旋律，却总在某一句突然忘词。

希望在演唱会现场，当灯光亮起、音乐响起时，可以不必盯着屏幕，而是和大家一起把喜欢的歌唱出来。

这不是一个专业的音乐产品，只是一个歌迷为自己制作的小工具。

### 🛠️ Built With

- HTML / CSS / JavaScript
- GitHub Pages
- A little help from AI
- A lot of love for Abel's music ♡

无需复杂环境或后端服务，轻量化运行。

### 🚀 Getting Started

点击上方 Live Demo，即可直接在浏览器中使用。

也可以将项目克隆到本地，打开 `index.html`。

iPhone 用户可以通过 Safari 的「分享 → 添加到主屏幕」，获得更接近独立 App 的使用体验。
